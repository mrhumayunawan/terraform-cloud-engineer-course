# Exam Preparation

---

## Step-00: Don't Stop, Get Certified
- If you have completed all the sections from 01 to 16, go ahead and get certified!  
- You should be able to score between **70% to 85%** on the exam with the knowledge gained from these sections.
- If you're aiming for an even higher score, I recommend revisiting the additional Terraform materials listed below.

---

## Step-01: Core Topics

### Key Points:
1. **Understand Infrastructure as Code (IaC) concepts**
2. **Understand Terraform's purpose** (compared to other IaC tools)
3. **Understand Terraform basics** (syntax, structure, etc.)
4. **Use the Terraform CLI** (outside of core workflow)
5. **Interact with Terraform modules**
6. **Navigate Terraform workflow** (from `init` to `apply` to `destroy`)
7. **Implement and maintain state** (understand state files, backends)
8. **Read, generate, and modify configuration** (HCL, variables, resources)
9. **Understand Terraform Cloud and Enterprise capabilities**

---

## Step-02: Questions Breakdown in the Real Exam

### Exam Overview:
- **Total Questions**: 57
  - **40 to 45 questions** will be **concept-oriented**, mostly straightforward. If you’ve completed the practicals above, you should be well-prepared to answer these.
  - **12 questions** will focus on practical aspects, such as asking basic commands, how to resolve certain error messages, etc. 
    - Don’t worry about tricky questions! The hands-on practicals in the course will provide the skills you need to tackle these.
    - Around **4 to 5 questions** might be challenging, but you’ve got this.
